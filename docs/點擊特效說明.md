# Mom Pet 點擊特效說明

點一下滑鼠時，點擊的地方會出現一圈光環和一些飛出去的小東西（以下叫「粒子」）。這些特效不是寫在程式裡的，而是一個資料夾裡的文字檔 `effect.txt`。只要改這個檔案，就能做出自己的特效：換顏色、換成自己的圖片，或者把「四散」改成「往下掉」「轉圈」「往上飄」。檔案裡只能寫數字和公式，碰不到電腦裡的檔案，所以從別人那裡拿到的特效可以放心用。

## 怎麼開始

1. 打開 Mom Pet 的設定頁，展開「點擊特效」，在下拉選單選一個想拿來改的特效。
2. 按「複製來改」。程式會把它複製一份到你的特效資料夾（`%LOCALAPPDATA%\MomPet\effects\`），切換成這份複本，並打開它的資料夾。
3. 用記事本打開裡面的 `effect.txt`，改完存檔（編碼用 UTF-8，記事本預設就是）。
4. 回到設定頁按「重新載入」，在桌面上點一下就能看到效果。檔案寫錯時，會跳出訊息告訴你第幾行、哪裡不對。

想把特效分享出去：把整個資料夾壓成 .zip 傳給別人，對方在設定頁按「匯入特效…」就好。匯出圖片包時，目前選的特效也會一起放進去。

## 檔案格式

每一行是「名稱 = 值」。`#` 後面是註解，程式不會讀；但寫顏色用的 `#8B1E3F`（`#` 後面剛好六個十六進位數字）不算註解。沒寫的項目會用預設特效的值，所以一個檔案只寫想改的那幾行也可以。

### 基本設定

| 名稱 | 意思 | 預設 |
| --- | --- | --- |
| `name` | 特效在選單裡顯示的名字 | 資料夾名稱 |
| `name.en`、`name.ja`、`name.zh-Hans`、`name.zh-Hant` | 各語言介面顯示的名字，沒寫就用 `name` | |
| `time` | 特效總長，單位秒（0.05 到 10） | 0.6 |
| `size` | 畫特效的小視窗大小，單位像素（20 到 800），點擊的位置在正中間。粒子飛得遠的話要調大，不然會被切掉 | 140 |

### 光環

| 名稱 | 意思 | 預設 |
| --- | --- | --- |
| `ring` | `on` 或 `off` | on |
| `ring.color` | 光環的顏色 | #8B1E3F |
| `ring.edge` | 光環外圈描邊的顏色 | #FFFFFF |
| `ring.radius` | 光環線條的半徑（公式） | 18.5 |
| `ring.width` | 光環線條的粗細（公式） | 3 |
| `ring.edge.width` | 外圈描邊的粗細（公式），0 就是不描邊 | 2 |
| `ring.scale` | 整個光環的放大倍率（公式） | `0.2 + 1.1 * easeout(time / 0.45)` |
| `ring.alpha` | 光環的不透明度（公式），1 是完全不透明，0 以下就不畫 | `1 - easeout(time / 0.45)` |

### 粒子

| 名稱 | 意思 | 預設 |
| --- | --- | --- |
| `particles` | 粒子數量（0 到 40） | 6 |
| `particle.x` | 粒子離點擊位置的水平距離，往右是正（公式） | `cos(angle) * (26 + 14 * r1) * ease(t)` |
| `particle.y` | 粒子離點擊位置的垂直距離，**往下是正**（公式） | `(sin(angle) * (26 + 14 * r1) + 14) * ease(t)` |
| `particle.scale` | 粒子的放大倍率（公式） | `0.4 + 0.6 * ease(t)` |
| `particle.spin` | 粒子轉了幾度，順時針是正（公式） | `(r2 - 0.5) * 120 * ease(t)` |
| `particle.alpha` | 粒子的不透明度（公式），0 以下就不畫 | `fade(t, 0.7)` |
| `particle.1`、`particle.2`…… | 粒子的樣子，第 1 顆用 `particle.1`、第 2 顆用 `particle.2`，用完再從頭輪 | 金色星星、酒紅愛心 |

粒子的樣子有四種寫法：

| 寫法 | 樣子 |
| --- | --- |
| `star #E8B84A` | 四角星，後面是顏色 |
| `heart #B8264F` | 愛心 |
| `dot #FFFFFF` | 小圓點 |
| `image sakura.png` | 自己的圖片。圖片要放在 `effect.txt` 同一個資料夾，只寫檔名。建議用背景透明的 PNG，程式會把它縮成最長邊 16 像素再乘上 `particle.scale` |

所有長度的單位都是像素（螢幕縮放 100%、角色大小 100% 時），程式會依螢幕縮放和設定頁的「大小」自動放大縮小。

## 公式

公式可以用數字、`+ - * /`、`%`（取餘數）、`^`（次方）和括號。每一顆粒子、每一幀都會算一次。

### 可以用的變數

| 變數 | 意思 |
| --- | --- |
| `t` | 特效進行到哪裡，從 0（剛點下去）到 1（`time` 秒結束） |
| `time` | 點下去之後過了幾秒 |
| `i` | 這是第幾顆粒子，從 0 開始 |
| `n` | 粒子總數 |
| `angle` | 把粒子平均排成一圈時，這顆的方向（弧度）；整圈每次點擊會隨機轉一個角度 |
| `r1`、`r2`、`r3` | 這顆粒子專屬的三個隨機數，在 0 到 1 之間。同一次點擊裡不會變，每次點擊都不同 |
| `pi` | 圓周率 3.14159… |

### 可以用的函式

| 函式 | 意思 |
| --- | --- |
| `sin(x)`、`cos(x)`、`tan(x)` | 三角函數，`x` 是弧度 |
| `abs(x)`、`sqrt(x)`、`floor(x)`、`round(x)` | 絕對值、平方根、無條件捨去、四捨五入 |
| `pow(x, y)` | x 的 y 次方，跟 `x ^ y` 一樣 |
| `min(a, b)`、`max(a, b)` | 比較小、比較大的那個 |
| `clamp(x, a, b)` | 把 x 限制在 a 到 b 之間 |
| `lerp(a, b, u)` | 從 a 到 b 走了 u（0 是 a，1 是 b） |
| `step(edge, x)` | x 到了 edge 就是 1，還沒到就是 0 |
| `ease(u)` | 先快後慢，預設特效飛出去用的曲線 |
| `easeout(u)` | 也是先快後慢，比 `ease` 溫和，光環用這個 |
| `easein(u)` | 先慢後快，適合往下掉、往裡縮 |
| `bezier(x1, y1, x2, y2, u)` | 自訂曲線，跟 CSS 的 `cubic-bezier(x1, y1, x2, y2)` 一樣 |
| `fade(u, start)` | u 到 start 之前是 1，之後慢慢降到 0。例如 `fade(t, 0.7)`：前 70% 的時間不透明，最後 30% 淡出 |
| `random(a, b)` | a 到 b 之間的隨機數。同一個公式裡寫兩次 `random` 會是兩個不同的數，但同一次點擊裡每一幀都一樣，粒子不會亂跳 |

`ease`、`easeout`、`easein` 的 u 小於 0 時當作 0，大於 1 時當作 1。

## 範例

### 改成往下掉（星星雨）

程式內建的「星星雨」就是這樣寫的：粒子在點擊的地方左右散開，然後越掉越快。

```
time = 1.0
size = 240
particles = 8
particle.x = (r1 - 0.5) * 60 + sin(t * 6 + i) * 4
particle.y = -10 + 110 * t * t
particle.scale = 0.6 + 0.4 * sin(t * pi)
particle.spin = (r2 - 0.5) * 360 * t
particle.alpha = fade(t, 0.6)
particle.1 = star #E8B84A
particle.2 = dot #FFFFFF
```

`t * t` 讓速度越來越快，像真的往下掉；`sin(t * 6 + i) * 4` 讓每顆左右輕輕晃，`+ i` 讓每顆晃的時機錯開。

### 往上飄的泡泡

```
time = 1.2
size = 220
ring = off
particles = 7
particle.x = (r1 - 0.5) * 50 + sin(t * 8 + r2 * 6) * 6
particle.y = -100 * easeout(t)
particle.scale = 0.5 + 0.8 * t
particle.spin = 0
particle.alpha = fade(t, 0.5)
particle.1 = dot #BFE6FF
particle.2 = dot #FFFFFF
```

### 繞著點擊的地方轉一圈

```
time = 0.9
particles = 8
particle.x = cos(angle + t * 2 * pi) * 30 * ease(t * 2)
particle.y = sin(angle + t * 2 * pi) * 30 * ease(t * 2)
particle.spin = t * 360
particle.alpha = fade(t, 0.6)
```

### 用自己的圖片（櫻花）

把 `sakura.png` 放進特效資料夾，然後寫：

```
particle.1 = image sakura.png
```

只寫這一行，其他沿用預設的四散動作，就變成櫻花花瓣往外散開。

## 常見問題

**改了沒反應**：記得存檔後在設定頁按「重新載入」。如果選單裡選的是內建特效，它在程式資料夾裡，請先按「複製來改」改那份複本。

**粒子被切掉一半**：飛出去的距離超過了小視窗，把 `size` 調大。小視窗是正方形，點擊位置在正中間，所以粒子最多只能離中心 `size` 的一半。

**跳出「第幾行」的錯誤**：照訊息看那一行。最常見的是括號沒配對、名字拼錯（變數和函式名稱不分大小寫）、顏色沒寫成 `#RRGGBB`，或圖片不在 `effect.txt` 同一個資料夾。
